# Python Day 146 - Password Manager

## Description
A Python-based Password Manager project that stores sample website account details in a JSON file and provides basic account management features.

## Features
- Add website accounts
- Display saved accounts
- Search accounts
- Delete accounts
- Generate random passwords
- Save records using JSON

## Files
- `password_manager.py` - Main Python program
- `passwords.json` - Sample account data

## How to Run
Keep both files in the same folder.

Run:

`python password_manager.py`

## Concepts Used
- JSON File Handling
- Lists and Dictionaries
- Functions
- Searching and Deleting
- Secrets Module
- Exception Handling

## Security Note
This is an educational project. Passwords are stored in plain text and must not be used for real credentials.
